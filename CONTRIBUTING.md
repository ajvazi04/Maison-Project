# Kontributet në MAISON

Faleminderit që dëshiron të kontribuosh.

## Si të fillosh

1. Hap një issue për gabimin ose idenë; trego hapat për ta përsëritur dhe çfarë prisje të ndodhte.
2. Bëj fork të depos dhe krijo një degë për ndryshimin.
3. Mbaj ndryshimet të përqendruara te një çështje dhe përditëso dokumentacionin kur duhet.
4. Para pull request-it, verifiko:
   - `npm run build`
   - `dotnet build Maison.Api/Maison.Api.csproj --configuration Release`
5. Në përshkrimin e pull request-it, shpjego ndryshimin dhe si e testove. Për ndryshime në pamje, shto pamje ekrani.

## Siguria dhe të dhënat

- Mos dërgo sekrete, skedarë `.env`, kredenciale, databaza SQLite apo të dhëna personale.
- Përdor vetëm të dhëna testuese kur provon porosi, llogari ose pagesa.
- Raporto dobësitë e sigurisë privatisht te mirëmbajtësi i depos; mos publiko udhëzime shfrytëzimi në një issue.
- Mos shto fotografi ose përmbajtje pa të drejta të qarta për publikim dhe ripërdorim.
